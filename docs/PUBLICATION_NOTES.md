# Notes for repository owners

- This is a prototype, not a completed laboratory information system or an
  automated public repository submission service. Review data and FAIRe
  completeness before external use.
- No licence is assigned in this package. Choose an organisation-approved
  software licence and attribution before making the repository public.
- The provided FAIRe and Wilderlab blank Excel files were not bundled. Obtain
  current copies from their maintainers and check whether their distribution
  terms permit mirroring.
- The mock CSV, JSON and results fixture use fictional identifiers and
  `demo@example.org`. Do not upload real voyage logs, GPS, sample data,
  contacts, FASTQ links, results or workbooks to a public repository without
  the project's data and privacy review.
- The CSV schema is a proposed DAP-to-IDC contract. Confirm UID reconciliation,
  environmental terms and collection-date rules with the relevant teams before
  using it for production data.
